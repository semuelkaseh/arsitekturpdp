Simulasi Conecta gov.br (Brasil)

Instansi mengambil data warga langsung dari pengelola data lewat satu platform API pusat. Akses setiap API harus disetujui pengelola datanya, setiap panggilan tercatat, dan setiap transaksi dihitung penghematannya. Tombol Indonesia memetakan padanannya.
